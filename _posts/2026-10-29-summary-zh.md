## [GitLab 严重远程代码执行漏洞源于 Ruby 正则整数溢出](https://alpinelinux.org/posts/GitLab-security-incident-CVE-2026-97229.html) ⭐️ 9.0/10

GitLab 发布了一份事后分析报告，详细说明了 CVE-2026-97229 的尝试利用情况，这是一个由 Ruby Onigmo 正则表达式引擎中的整数溢出引起的严重远程代码执行漏洞。该漏洞允许攻击者从不受信任的输入中编译恶意正则表达式，从而导致原生代码执行。 该事件不仅影响 GitLab，还影响任何从不信任源编译正则表达式的应用程序，给 DevSecOps 生态系统和自托管部署带来重大风险。对容器镜像中不可变标签的依赖受到了挑战，凸显了安全补丁策略中的运营风险。 根本原因是 Onigmo C 库中的整数溢出，需要修补特定版本的 Ruby，不支持的旧版 Ruby 将不会获得安全修复。建议组织审计现有的 CI/CD 配置文件，查找复杂或不安全的正则表达式以降低风险。

hackernews · sashk · 10月28日 23:45 · [社区讨论](https://news.ycombinator.com/item?id=50282544)

**背景**: GitLab 是一个流行的 DevOps 平台，包含一个使用 Ruby 编程语言编译用户定义正则表达式的 CI/CD 引擎。Onigmo 库是 Ruby 使用的正则表达式引擎，如果它处理不受信任的输入，其中的漏洞可能导致远程代码执行。整数溢出是一种数学运算结果超出数据类型可容纳值的错误，可能导致内存损坏。

## [Qwenputer 在 Qwen3.5 模型中嵌入确定性 RISC-V CPU](https://divagr.com/blog/qwenputer) ⭐️ 8.0/10

一篇博客文章展示了“Qwenputer”，这是一个编译进 Qwen3.5 4B 语言模型权重中的完全功能化且确定性的 RISC-V CPU。该系统利用模型的 Gated DeltaNet 层作为 RAM，并成功在前向传播中运行 C 和 MicroPython 代码以执行精确算术运算。 这项探索了神经网络与计算架构新颖交叉领域，挑战了大语言模型是否能通过训练权重有效学习确定性 CPU 逻辑的观念。它为神经架构在类硬件逻辑操作中的表示能力提供了独特见解。 该实现专门依赖于 Qwen3.5 4B 变体，并利用其 Gated DeltaNet 层作为随机存取存储器。与典型的概率性 LLM 输出不同，这个嵌入式 CPU 确保精确计算具有确定性的执行。

hackernews · csmantle · 10月29日 00:25 · [社区讨论](https://news.ycombinator.com/item?id=50282838)

**背景**: RISC-V 是一种开放标准的精简指令集计算机架构，采用负载存储设计，指令仅与寄存器交互。像 Qwen3.5 这样的大语言模型通常是为概率性文本生成而训练的，因此在其中嵌入一个硬性的确定性计算机架构是一项关于神经网络能力的高度非常规实验。

## [JavaScript 指纹脚本被重新利用以绕过 LLM 安全过滤器](https://nullpt.rs/fingerprinting-bioweapons) ⭐️ 8.0/10

安全研究人员展示了一种新的攻击向量，其中看似无害的 JavaScript 指纹脚本被重新用于走私生物武器相关内容并绕过大型语言模型（LLM）的安全指南。这种技术利用了 LLM 处理代码的能力来规避针对恶意提示的标准防御措施。 这一发现凸显了 AI 安全过滤器与攻击者之间不断升级的军备竞赛，表明像 JS 混淆器这样的传统 Web 安全工具可能被征用以击败 LLM 防御。它预示着 AI 安全必须将动态代码执行和混淆技术纳入考量，以防止危险信息的泄露。 该技术使用动态 JS 混淆库创建蜜罐，引诱 LLM 机器人并测试其混淆是否阻止爬取。社区发现表明，某些模型（如 GLM-5.3）可能会意外地遵循这类混淆的恶意提示，而其他模型则不会。

hackernews · hazebooth · 10月28日 17:13 · [社区讨论](https://news.ycombinator.com/item?id=50276998)

**背景**: JavaScript 指纹脚本通常由 Web 服务器用于识别独特的浏览器和设备，常用于反机器人或安全目的。大型语言模型（LLM）正日益成为“提示注入”攻击的目标，攻击者通过恶意输入诱使 AI 忽略其安全指令。混淆技术隐藏代码或文本的意图，使安全系统难以检测恶意负载。

**社区讨论**: 社区成员称赞了这项调查，有人指出像 GLM-5.3 这样的特定模型可能更容易受到这类混淆攻击的影响。其他人讨论了该技术对 Web 安全的更广泛影响，将其比作被遗忘的水印导致文档被隔离，并猜测了其中涉及的多层误导的复杂性。
