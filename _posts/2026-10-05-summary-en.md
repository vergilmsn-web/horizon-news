## [Jailbroken PS5 Can Run Original Xbox Games via XPSemu Port](https://www.techpowerup.com/353381/halo-2-reportedly-runs-at-30-fps-on-a-jailbroken-ps5-thanks-to-new-xbox-emulator) ⭐️ 6.5/10

Developer ZiZc3 published XPSemu Alpha 1 on GitHub, a port of the open-source xemu emulator that runs natively on jailbroken PS5 hardware. Benchmarks show Halo 2 reaches 30 FPS on average, with a 60 FPS patch allowing gameplay at 36-50 FPS. This demonstrates the PS5's GPU capabilities are sufficient for legacy console emulation, providing a pathway for gamers to access out-of-print Xbox titles directly on PlayStation hardware. It follows a wave of jailbreak tools that expand homebrew features across multiple console ecosystems. The emulated CPU thread remains at 85-97% load while the GPU sits idle, indicating that the original Xbox workload is heavily CPU-bound on the PS5. Users must provide their own Xbox BIOS and MCPX boot ROM to boot games, as disc support is unavailable.

rss · TechPowerUp News · Oct 4, 18:23

**Background**: xemu is a QEMU-based open-source project that emulates the original Microsoft Xbox console for Windows and Linux. The xemu project requires specific BIOS and flash ROM files to function, as its DRM implementation is incomplete for stock retail hardware. XPSemu is a specialized build that ports this emulator to the PS5's custom architecture, requiring a jailbreak to bypass system security restrictions.

A community-driven script called RemoveMacAI was released to disable Apple Intelligence on macOS 27, allowing users to reclaim approximately 12GB of disk space. The tool reflects growing user frustration with forced AI features in operating systems, mirroring historical issues with bloated Windows installations. It highlights a significant shift in user expectations regarding system customization and privacy, as competitors like Microsoft have moved toward global AI switches for easier control. The script specifically targets macOS 27 and removes components responsible for AI features, freeing up roughly 12GB of storage on Apple products with small SSDs. The release of such third-party tools indicates that the current AI integration is perceived by many users as outdated and unhelpful compared to other AI providers.

hackernews · privacyisntdead · Oct 4, 19:42 · [Discussion](https://news.ycombinator.com/item?id=49957116)

**Background**: Apple Intelligence is a suite of generative AI features that Apple has integrated into its ecosystem, including macOS, iOS, and Siri. In recent operating system updates, these AI components are installed by default and can consume significant disk space, approximately 12GB, which is a notable portion of storage on Apple's hardware. Historically, macOS was considered more minimalist than Windows, but users are now resorting to third-party 'de-crufting' tools to remove unwanted software.
