## [Open-source UEFI tool lifts Nvidia's half-speed GPU AI limiter on Windows](https://www.tomshardware.com/pc-components/gpus/open-source-usb-tool-unlocks-nvidias-half-speed-gpu-ai-limiter-on-windows-lifts-gpus-fp16-math-performance-up-to-65-percent-uefi-unlocker-covers-rtx-20-30-and-40-series-desktops-and-laptops) ⭐️ 6.5/10

An open-source UEFI tool named nv-uefi-unlocker bypasses Nvidia's Windows tensor rate cap on RTX 20, 30, and 40-series GPUs. This workaround unlocks up to 65% faster FP16 AI performance. This tool provides a free method for AI practitioners and gamers to maximize inference performance on existing hardware without waiting for a new driver release. It addresses a significant software limitation rather than requiring a fundamental hardware upgrade. The specific 65% performance boost applies to FP16 AI workloads, which are heavily utilized in modern neural network inference. The tool operates via UEFI to lift the cap specifically on desktops and laptops running Windows.

rss · Tom's Hardware · Nov 1, 14:00

**Background**: Nvidia's 'half-speed GPU AI limiter' refers to a software restriction in Windows that caps tensor processing unit rates, limiting FP16 performance. UEFI is the modern firmware interface that allows advanced hardware configuration before the operating system loads. FP16 is a 16-bit floating-point data format widely used in AI to balance speed and precision.

## [Lenovo's Fingerprint USB Drive Revealed as Unencrypted SD Card](https://www.reddit.com/r/technology/comments/1xl2pr3/lenovos_encrypted_fingerprint_usb_drive_is_just/) ⭐️ 6.0/10

Researchers discovered that Lenovo's ThinkPlus FU100 fingerprint USB drive functions as a simple unencrypted SD card inside a protective case. This finding exposes the device's security mechanism as a facade, with the actual encryption and key management absent from the hardware. This failure undermines consumer and enterprise trust in hardware security vendors, suggesting that 'secure' labels on physical devices may not reflect actual cryptographic protections. It highlights the risk of relying on hardware vendors for sensitive data storage without independent verification. The flaw in the ThinkPlus FU100 was identified in August 2025, resulting in the issuance of CVE-2025-13453 in January 2026. The product, first announced in 2019, was primarily available in China, explaining the delayed public disclosure of the security lapse.

hackernews · entryleveljobsc · Nov 1, 14:34 · [Discussion](https://news.ycombinator.com/item?id=50326099)

**Background**: Fingerprint-enabled USB drives are designed to replace traditional password authentication with biometric access for convenient data security. However, true hardware encryption requires a secure element to store keys, whereas many consumer devices use software-based encryption that can be easily bypassed if the physical storage medium is not protected.
