## [Nvidia Mandates TSMC 3nm Base Dies for NVHBM Across Major Memory Partners](https://www.electronicsweekly.com/news/business/samsung-micron-hynix-to-use-tsmc-base-dies-for-nvhbm-2026-10/) ⭐️ 9.0/10

Nvidia has mandated that Samsung, Micron, and SK Hynix use base dies manufactured on TSMC's 3nm node for its custom NVHBM memory standard. This protocol is required for NVHBM, which integrates the memory controller into the HBM stack to offer up to 30% more bandwidth than standard HBM4e. This move significantly increases TSMC's control over the AI accelerator memory supply chain by making all major HBM manufacturers dependent on its advanced logic production. It forces competitors like Samsung to purchase wafers from TSMC instead of using their in-house fabs for critical components, shifting the balance of power in the semiconductor industry. The TSMC 3nm mandate specifically applies only to the base die, which handles controller logic, while the actual memory layers will continue to be produced by partners using their own 10nm DRAM processes. Nvidia's intellectual property is specifically optimized for TSMC's manufacturing node, which necessitates this cross-competitor supply arrangement.

rss · Electronics Weekly · Oct 19, 05:15

**Background**: High Bandwidth Memory (HBM) is a 3D-stacked memory technology consisting of multiple DRAM layers connected via Through-Silicon Vias, placed atop a logic 'base die'. The base die acts as the controller for the stack, managing data access and communication with the processor. NVHBM is Nvidia's proprietary standard that moves the controller onto the base die to improve bandwidth and power efficiency over standard HBM4e.
