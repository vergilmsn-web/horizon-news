## [Dux 从 DMS 更名，新增原子发行版支持和文件管理器](https://duxlabs.dev/) ⭐️ 6.0/10

Dux（原名 Dank Material Shell，简称 DMS）已更名并发展为一个成熟的 Wayland 桌面外壳。它最近为 Bazzite 等原子 Linux 发行版添加官方支持，并具备文件管理器和主题定制功能。 这一进展降低了热门不可变发行版用户采用 Niri 和定制 Wayland 配置的门槛，消除了之前的安装摩擦。它表明轻量级、高可定制性的 Wayland 外壳正变得更加主流和可用。 Dux 由 Quickshell 和 Go 构建，为窗口和通知管理提供统一界面。它与多个 Wayland 合成器兼容，包括 Niri、Hyprland、Sway 和基于 River 的系统。

hackernews · indigodaddy · 11月8日 19:08 · [社区讨论](https://news.ycombinator.com/item?id=50416053)

**背景**: Wayland 是一种现代显示服务器协议，取代了老旧的 X11 系统，为 Linux 桌面提供更好的性能和安全性。桌面外壳是用户与合成器交互的界面层，类似于 GNOME Shell 或 KDE Plasma。原子或不可变 Linux 发行版将系统文件设为只读，以防止更新破坏操作系统。

## [Paul Ford 认为 Web 浏览器可以取代原生应用程序](https://ftrain.com/aboard-the-web-is-more-than-enough) ⭐️ 6.0/10

Paul Ford 发表了一篇观点文章，认为现代 Web 浏览器的性能足以取代大多数场景下的原生应用程序。包括 Simon Willison 在内的社区成员通过提及 WebAssembly 和 three.js 等 Web API 的快速发展，支持了这一观点。 这一观点对软件生态系统具有重要意义，因为它强调了在 Web 上构建桌面级功能时，开发成本和访问门槛正在不断降低。它鼓励开发人员重新审视对原生开发工具的依赖，并突显了前端技术的成熟度。 支持者指出，离线存储、Server-Sent Events (SSE) 和 WebAudio 等功能如今每周都被频繁用于构建复杂应用程序。然而，批评者认为浏览器可能会像 systemd 一样变得过于臃肿，且某些任务仍更适合使用原生应用程序。

hackernews · edward · 11月8日 19:48 · [社区讨论](https://news.ycombinator.com/item?id=50416456)

**背景**: 传统上，开发人员需要针对特定的操作系统构建软件，这意味着必须为 macOS、Windows 和 Linux 维护不同的代码库。Web 标准和浏览器的演进使得开发人员能够在无需原生安装的情况下，提供精致的跨平台体验。像 WebAssembly 这样的技术使得在浏览器中直接运行高性能代码成为可能。

**社区讨论**: 社区观点存在分歧，Simon Willison 等用户通过每周多次使用现代 Web API 构建功能，热情地支持了该文论点。也有人担心浏览器正变得过于复杂和具有侵入性，将其与 systemd 进行不利对比。一条元评论指出，HN 的大多数用户是 Web 开发者，他们自然地倾向于使用前端框架。
