## [Open-Source 'Phantom Drive' USB Hides Encrypted Partition Behind Decoy](https://www.tomshardware.com/pc-components/usb-flash-drives/open-source-stealth-usb-hides-an-encrypted-partition-behind-an-8gb-decoy-drive-phantom-drive-appears-as-a-regular-usb-stick-until-you-create-a-text-file-to-unlock-the-hidden-data) ⭐️ 6.5/10

A new open-source project called 'Phantom Drive' creates a USB stick that appears as a standard 8GB drive but contains a hidden encrypted partition. The hidden partition is unlocked by creating a text file containing a password, which the custom firmware intercepts and hashes in the microcontroller's SRAM without ever writing the password to storage. This project offers a practical DIY approach to plausible deniability encryption, allowing users to hide sensitive data in plain sight behind a seemingly innocuous USB stick. It is relevant for journalists, activists, researchers, and privacy-conscious users who need protection against coercive data extraction or forensic inspection. The firmware derives AES-XTS (or AES-256) keys from the password, and the drive automatically unmounts and remounts itself during the unlock process. Because the password is only ever hashed in volatile SRAM, it leaves no forensic footprint in flash storage, making it harder to prove a hidden volume even exists.

rss · Tom's Hardware · Aug 9, 12:00

**Background**: Plausible deniability encryption is a cryptographic technique where the existence of encrypted data can be plausibly denied, even under coercion; tools like VeraCrypt implement this through hidden volumes that are statistically indistinguishable from random data. Custom USB microcontroller firmware allows hobbyists to reprogram low-level device behavior, intercepting USB mass-storage commands and managing partitions in ways off-the-shelf drives cannot. SRAM (Static RAM) is volatile memory on the microcontroller that loses its contents when power is removed, making it ideal for handling sensitive intermediate values like password hashes without leaving persistent traces.

## [Yusuke Endoh creates a Piet quine: a self-replicating GIF](https://www.tomshardware.com/software/programming/mind-bending-self-replicating-gif-code-prints-an-exact-copy-of-itself-is-both-a-program-and-its-own-visual-output-champion-coder-shows-off-piet-quine-technique) ⭐️ 5.5/10

Champion coder Yusuke Endoh has created a 'Piet Quine' — a 252×189 GIF image that functions as both a Piet program and its own exact visual output, printing itself byte-for-byte when executed. This achievement merges two fascinating concepts in computer science — esoteric visual programming and self-reproducing programs — into a single artifact, demonstrating remarkable technical creativity. It highlights the depth of play in programming languages beyond mainstream tools, inspiring interest in computability theory and creative coding. Piet is a stack-based esoteric language in which programs are images made of 20 colors arranged in 18 cyclically related hues and lightness steps; commands are determined by color transitions between adjacent pixels. The challenge of a Piet quine lies in encoding executable logic while simultaneously making the image pixel-identical to the GIF file it outputs — a constraint requiring careful data encoding within the color blocks themselves.

rss · Tom's Hardware · Aug 9, 11:40

**Background**: A quine, named after philosopher and logician Willard Van Orman Quine, is a program that takes no input and outputs an exact copy of its own source code — a classic exercise in computability theory. Piet, created by David Morgan-Mar, is an esoteric language where programs resemble abstract paintings (inspired by Piet Mondrian), with execution governed by color changes between pixels rather than textual syntax. Combining these concepts means the image file must simultaneously be valid Piet source code and the exact byte sequence that code produces as output.

## [Owner of Original Intel 8080 Rubylith Mask Seeks Skilled Restorer](https://www.tomshardware.com/pc-components/cpus/owner-of-original-intel-8080-pre-production-layout-seeks-restorer-handcrafted-rubylith-mask-shows-5-000-transistors-and-interconnect-patterns-of-the-fabled-2-mhz-cpu) ⭐️ 5.5/10

The owner of the original engineering copy of the Intel 8080 Rubylith pre-production mask is publicly seeking a skilled restorer to preserve the historic handcrafted artifact, which displays the layout of approximately 5,000 transistors and their interconnect patterns for the legendary 2 MHz CPU. This artifact represents one of the earliest physical design documents of a microprocessor that defined the 8-bit computing era, making its preservation crucial for computing history; the same mask was previously photographed alongside Andy Grove, Robert Noyce, and Gordon Moore in 1978, underscoring its cultural and historical significance to the hardware community. The Rubylith mask was a hand-cut red-and-clear sheet used in pre-digital era chip design, later reduced photographically to produce photolithography masks; the Intel 8080, released in April 1974, was an 8-bit microprocessor partially backward-compatible with the Intel 8008.

rss · Tom's Hardware · Aug 9, 11:00

**Background**: Rubylith is a brand of masking film invented by the Ulano Corporation, consisting of clear and red layers that engineers would hand-cut and peel to create design patterns. In early semiconductor manufacturing, these handcrafted patterns were photographically reduced multiple times to produce photolithography masks used to transfer circuit patterns onto silicon wafers. The Intel 8080, designed by Federico Faggin and released in 1974, became one of the most influential 8-bit microprocessors and helped launch the personal computer revolution.
