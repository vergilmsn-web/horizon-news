Intel has updated its Compute Runtime to support PISA, a new portable virtual ISA and programming model. This innovation introduces an abstraction layer that allows a single compiled workload to be finalized for multiple compatible Intel GPU architectures. PISA addresses the common 'ISA fragmentation' challenge in GPUs by reducing the need for architecture-specific code generation for every new generation. This is a significant step toward standardizing the Intel GPU software stack and improving compatibility for high-performance computing. While a workload compiled to PISA can run across multiple architectures without source code changes, actual compatibility depends on the specific target hardware and its supported features. PISA is an evolution of Intel's existing vISA, which has long served as an intermediate representation but lacked the same portable programming model.

rss · TechPowerUp News · Sep 21, 13:22

**Background**: Unlike mature CPU ISAs such as x86 or Arm, GPU native instruction sets vary significantly across different hardware generations and architectures. Traditional compilers must target specific machine ISAs, making it difficult to run the same software across different GPU generations without recompilation. A virtual ISA creates a stable intermediate representation that compilers can target, which is then optimized into native machine code for the specific hardware at runtime.
