## [HTTP/2 远程代码执行漏洞需显式启用 Brotli 解码器](https://nitter.click/AikidoSecurity/status/2113759110625906950?__galadriel=lPmlGl9id4oAd5UeBwMhlYKArHyr6lR2IDGujPwB5HV2kQ1aLoPWFd5A9sGuzNcmrp8fUso8qygmHcKTDZ8MNHWqQ3bDJcycV87xp_0VypzQLYj6O_RRHlZuQqj33oASGY2YLSoAiMjeOZN40h7Stf8AG7DPrGZbAPVKUXy36HoMudRbvwF3_r2uYNmfJMhpKzywQDM6Ab8) ⭐️ 8.0/10

研究人员发现 HTTP/2 相关库中存在一个新的远程代码执行（RCE）漏洞，主要涉及 Brotli 解压缩功能，影响 Node.js 和 Python。由于有漏洞的 Brotli 解码器必须由开发者显式启用，因此默认的服务器配置不会触发该漏洞。 此披露对安全工程师和系统管理员意义重大，因为它澄清了 Web 服务的风险评估情况。它避免了运行默认配置的组织的过度恐慌，同时强调了修补显式使用有漏洞解码器的依赖项的紧迫性。 由于服务器通常默认不启用 Brotli 解码器，该漏洞对客户端的影响比服务器更严重。特定软件版本受到影响，1.2.0 以下的 Brotli 版本存在漏洞，而 Python 包已更新至 1.2.1 版本以修复此问题。

hackernews · cowlevel · 10月23日 23:30 · [社区讨论](https://news.ycombinator.com/item?id=50216791)

**背景**: HTTP/2 是 HTTP 网络协议的最新修订版，相比 HTTP/1.1 具有显著的性能提升。Brotli 是由谷歌开发的压缩数据格式和算法，广泛用于在传输过程中缩小 HTML、CSS 和 JavaScript 等 Web 资源的尺寸。远程代码执行（RCE）漏洞允许攻击者在服务器上执行任意命令，可能导致系统完全失守。

**社区讨论**: 社区情绪在技术验证和对威胁严重程度的怀疑之间分歧。许多用户认为该漏洞对服务器而言被夸大其词，因为解码器默认未启用；而其他人则质疑为何常规内存 bug 会收到如此耸人听闻的命名和营销炒作。
