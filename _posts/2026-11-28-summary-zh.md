## [Unkernel 将真实 Linux 内核编译为 WebAssembly 以便在浏览器中运行](https://unkernel.dev/) ⭐️ 8.0/10

Unkernel 是一个成功将真实 Linux 内核编译为 WebAssembly 的项目，使其能够在 Web 浏览器中在一秒内启动至 Shell。该方法允许并发的用户进程直接在浏览器环境中运行，使用名为 kwemu 的自定义 aarch64 CPU 模拟器。 该项目通过允许非 Web 原生软件在浏览器中安全运行，展示了 Web 隔离和仿真领域的重大突破。它为在受限沙箱中运行系统级工具和展示 WebAssembly 处理复杂计算任务的能力开辟了新途径。 该实现依赖于 kwemu，这是一个用 Zig 编写的 aarch64 CPU，它被链接到内核中，通过遍历内核自身的页表，使用真实的 Linux 代码来处理内存管理。该系统支持并发性（如多个并行进程所示），但不支持嵌套虚拟化。

hackernews · nreece · 11月28日 03:19 · [社区讨论](https://news.ycombinator.com/item?id=50674218)

**背景**: WebAssembly (Wasm) 是一种二进制指令格式，旨在提供可在包括 Web 浏览器在内的多个平台上运行的可移植、低级别代码模型。像 Linux 这样的完整操作系统内核编译为 Wasm 是一项高级系统研究工程，需要模拟 CPU 架构并手动管理内存，因为内核在此情境下无法使用标准操作系统服务。与传统的 QEMU 风格模拟器不同，Unkernel 仅模拟用户程序，而运行实际的 Linux 内核代码。

## [谷歌 DeepCrossAttention 提升 Transformer 效率](https://research.google/blog/supercharging-transformer-residual-connections/) ⭐️ 8.0/10

谷歌研究团队推出了 DeepCrossAttention，一种通过跨层而非仅跨令牌应用注意力机制来增强 Transformer 中残差学习的方法。该创新在保持可比模型质量的同时，实现了高达 3 倍的推理速度提升。 此优化对 AI 行业意义重大，因为它降低了大型语言模型的计算成本并提高了速度。通过解决传统注意力机制扩展的高成本问题，它有助于使先进的 AI 能力更加普及和高效。 该机制使用可学习的、依赖于输入的权重来动态组合先前的层嵌入，从而在不产生典型计算惩罚的情况下解锁模型的完整历史上下文。这种深度向交叉注意力专门作用于层之间的残差连接。

hackernews · ComputedCamp995 · 11月27日 23:06 · [社区讨论](https://news.ycombinator.com/item?id=50672565)

**背景**: 标准的 Transformer 模型使用注意力机制来处理序列中的令牌，但残差连接只是将每层的输出加到原始输入上。随着模型层数增加，管理这种信息流动变得复杂且计算成本高昂。DenseNet 是一种已知架构，它将层连接到所有后续层，这一概念与这项新研究的跨层关注点类似。
