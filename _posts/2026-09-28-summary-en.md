## [Xcena MX1 Tackles Memory Bottlenecks with CXL and RISC-V](https://www.eetimes.com/xcena-cuts-data-movement-to-address-memory-bottlenecks/) ⭐️ 6.0/10

Xcena has developed the MX1, a system that uses Compute Express Link (CXL) to integrate DDR5 memory, SSDs, and RISC-V cores. The architecture aims to push compute into memory to reduce data movement and mitigate memory bandwidth limitations. Addressing the memory wall is critical for scaling AI and data-intensive workloads, where moving data between memory and processors is a major performance bottleneck. By combining CXL's shared memory capabilities with on-die RISC-V compute, Xcena offers an alternative approach to easing memory bandwidth limitations and lowering system latency. The MX1 architecture specifically combines DDR5 and SSDs with RISC-V cores, and the design aims to ease programmability in addition to reducing data movement. This represents a novel hardware approach that treats memory as a co-processor rather than just passive storage.

rss · EE Times · Sep 28, 07:30

**Background**: In modern computing, memory bandwidth has become a severe constraint known as the 'memory wall.' As datasets for AI grow, the time spent fetching data from memory or SSDs often exceeds the actual time spent computing. CXL (Compute Express Link) is a new technology that allows different chips to share memory pools and communicate over a high-speed link, while RISC-V is an open-standard instruction set architecture that enables custom, low-power processors to be built directly onto memory chips.
