## [Protomaps Simplifies Self-Hosting Map Tiles for Developers](https://bruceroettgers.eu/blog/protomaps/) ⭐️ 7.0/10

Protomaps introduces a system that allows developers to deploy global, interactive maps as a single static file using the PMTiles format, removing the need for intermediate server infrastructure. The platform is now recognized for making self-hosting cheap and easy compared to traditional commercial APIs. This significantly reduces the cost and complexity of integrating maps into web applications by enabling static hosting on services like Cloudflare R2 or S3, providing a privacy-friendly open-source alternative to proprietary providers. The core technology is PMTiles, an open archive format for pyramids of tile data accessible via HTTP Range Requests. Large raster formats, particularly high-resolution satellite imagery, remain difficult to host cost-effectively due to significant storage requirements.

hackernews · bcye · Nov 15, 19:26 · [Discussion](https://news.ycombinator.com/item?id=50509837)

**Background**: Traditional map providers like Mapbox or Google Maps require developers to use their proprietary APIs and servers, which can be expensive and raise privacy concerns. Protomaps leverages open-source data like OpenStreetMap to package the world into a format that can be served directly to users' browsers from standard cloud storage.

## [MacBook Pro OLED PWM Flicker Concerns Highlighted by Technical Analysis](https://macanorak.com/the-macbook-pros-oled-pwm-problem-when-a-better-display-becomes-worse-to-use/) ⭐️ 7.0/10

A technical analysis argues that the new OLED display in the MacBook Pro may suffer from significant pulse-width modulation (PWM) flicker, sparking a high-engagement discussion about display health. The analysis triggered a substantive debate regarding the actual PWM frequency, with some suggesting that tandem OLED layers may operate out of phase to mitigate perceived flicker. This issue is significant because PWM flicker can cause headaches and visual fatigue for a subset of users, potentially impacting the adoption of new hardware. It highlights a critical human-computer interaction challenge where advanced display technology may not be universally comfortable to use. Community members corrected initial assumptions about the PWM frequency, noting that 240Hz measurements might actually be 480Hz or even 960Hz due to the out-of-phase operation of tandem OLED layers. Researchers cited indicate that humans can perceive flicker at frequencies more than double the display's rate.

hackernews · MacAnorak · Nov 15, 13:15 · [Discussion](https://news.ycombinator.com/item?id=50506719)

**Background**: OLED displays use Pulse-Width Modulation (PWM) to control brightness by rapidly switching pixels on and off. While high-frequency PWM is generally invisible, some individuals are highly sensitive to these rapid changes, leading to symptoms like migraines and eye strain. This sensitivity is a well-documented phenomenon that affects how display technologies are perceived in consumer electronics.

**Discussion**: The discussion features strong technical disagreements about the actual flicker frequency, with users debating whether tandem OLED layers effectively double the PWM rate.
