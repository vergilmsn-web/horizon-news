## [Protomaps 让开发者轻松自托管地图瓦片](https://bruceroettgers.eu/blog/protomaps/) ⭐️ 7.0/10

Protomaps 推出了一项允许开发者使用 PMTiles 格式将全局交互式地图作为单个静态文件部署的系统，无需中间服务器基础设施。该平台现在被认为比传统商业 API 更易于进行低成本、简单的自托管。 通过在类似 Cloudflare R2 或 S3 的服务上进行静态托管，这大幅降低了将地图集成到 Web 应用中的成本和复杂性，并为隐私提供了友好的开源替代方案，替代专有提供商。 核心技术是 PMTiles，一种可通过 HTTP Range 请求访问的瓦片数据金字塔开放归档格式。由于存储需求巨大，大尺寸光栅格式（尤其是高分辨率卫星图像）在经济上仍难以有效托管。

hackernews · bcye · 11月15日 19:26 · [社区讨论](https://news.ycombinator.com/item?id=50509837)

**背景**: 传统的地图提供商（如 Mapbox 或 Google Maps）要求开发者使用其专有 API 和服务器，成本可能很高且存在隐私问题。Protomaps 利用 OpenStreetMap 等开源数据，将世界打包成一种可直接从标准云存储发送到用户浏览器的格式。

## [技术分析揭示 MacBook Pro OLED PWM 闪烁问题](https://macanorak.com/the-macbook-pros-oled-pwm-problem-when-a-better-display-becomes-worse-to-use/) ⭐️ 7.0/10

一项技术分析指出，MacBook Pro 新的 OLED 显示屏可能存在严重的脉冲宽度调制（PWM）闪烁问题，引发了关于显示健康的热烈讨论。该分析引发了关于实际 PWM 频率的实质性辩论，有人建议串联 OLED 图层可能以反相运行以减轻感知闪烁。 此问题意义重大，因为 PWM 闪烁可能会使部分用户出现头痛和视觉疲劳，进而影响新硬件的普及。它凸显了人机交互中的一个关键挑战，即先进的显示技术并不一定能让所有用户感到舒适。 社区成员纠正了关于 PWM 频率的初始假设，指出 240Hz 的测量结果实际上可能高达 480Hz 甚至 960Hz，这是由于串联 OLED 图层反相运行所致。被引用的研究表明，人类能够感知到频率高于显示速率两倍的闪烁。

hackernews · MacAnorak · 11月15日 13:15 · [社区讨论](https://news.ycombinator.com/item?id=50506719)

**背景**: OLED 显示屏通过脉冲宽度调制（PWM）快速开关像素来控制亮度。虽然高频 PWM 通常肉眼不可见，但某些个人对这些快速变化高度敏感，会导致偏头痛和眼部疲劳等症状。这种敏感性是一种有据可查的现象，影响着显示技术在消费电子中的感知效果。

**社区讨论**: 讨论中存在关于实际闪烁频率的强烈技术分歧，用户们辩论串联 OLED 图层是否有效提高了 PWM 频率。情绪混合但普遍担忧，用户分享了因脑震荡或对运动模糊及显色指数（CRI）敏感而导致的屏幕相关问题的个人经历。

## [英特尔在第三季度凭借台式机份额回升夺回整体 CPU 市场份额](https://www.tomshardware.com/pc-components/cpus/intel-reclaims-overall-cpu-market-share-for-the-first-time-since-2025-massive-desktop-gains-offset-amds-record-server-and-mobile-growth) ⭐️ 6.5/10

根据 Mercury Research 的第三季度报告，英特尔自 2025 年以来首次夺回整体 CPU 市场份额。这一转变由台式机领域的大幅增长驱动，成功抵消了 AMD 在服务器和移动市场的创纪录增长。 这一市场份额反转凸显了 x86 生态系统内不同的竞争动态，表明台式机与服务器细分市场已不再同步增长。这表明了重要的行业趋势，即英特尔在客户端计算的传统优势正在影响其整体市场领先地位，尽管其在数据中心领域面临压力。 报告特别指出，第三季度客户端 CPU 销售下降，而 AMD 同时实现了创纪录的服务器 CPU 市场份额。需要明确的是，英特尔台式机份额的回升归因于季节性反弹以及对 2026 年早前供应不足的修正。

rss · Tom's Hardware · 11月15日 13:30

**背景**: x86 CPU 市场通常划分为服务器、台式机和移动（客户端）细分市场，每个细分市场面临不同的竞争压力。Mercury Research 是一家知名的第三方数据公司，负责跟踪并发布主要微处理器厂商按季度计算的出货量和市场份额预测。跟踪这些数据对于理解企业 IT 采购和消费类硬件趋势至关重要。
