## [Cloudflare 宣布推出 TypeScript 编译器的 Rust 移植版本 tsrs](https://blog.cloudflare.com/typescript-rust-port/) ⭐️ 9.0/10

Cloudflare 和 VoidZero 团队宣布了 tsrs，这是 TypeScript 编译器的高性能 Rust 移植版本，比标准的基于 Go 的实现快最多 8 倍，内存使用量减少 70%。该项目专门设计为让编译器能够在 WebAssembly 沙箱中运行，而无需加载完整的 Go 运行时环境。 这一发展对 Web 开发者意义重大，因为它提供了一个更快的类型检查工具，该工具可以安全地运行在基于浏览器或无服务器沙箱环境中。它还展示了一种可行的架构模式，允许在无需依赖运行时垃圾回收器的情况下，将复杂的基于垃圾回收的系统迁移到 Rust。 为了克服 Rust 缺乏内置垃圾回收器的问题，tsrs 项目采用了一种基于长期存活区域的自定义内存模型，这些区域永远不会被显式释放。该技术有效地模拟了垃圾回收语义，同时保持了 Rust 严格的内存安全保证，并避免了传统垃圾回收器的运行时开销。

hackernews · hnisjafx40 · 10月20日 13:18 · [社区讨论](https://news.ycombinator.com/item?id=50165953)

**背景**: 标准的 TypeScript 编译器目前是用 Go 编写的，当将其编译到 WebAssembly 以在隔离环境中使用时，需要导出整个 Go 运行时。相比之下，Rust 是一种系统级语言，通过其所有权模型在编译时保证内存安全，并且不包含内置的运行时垃圾回收器。这使得在 Rust 中移植严重依赖动态对象图（例如编译器）的应用变得具有挑战性，需要采用自定义的内存管理策略。

## [威胁行为者攻陷了五分之一的 Tor 出口节点发动中间人攻击](https://www.solidot.org/story?sid=85666) ⭐️ 8.3/10

攻击者攻陷了 333 个 Tor 出口节点以部署 Ebury 恶意软件，从而拦截未加密的电子邮件并实施 SSH 中间人攻击。Tor 项目团队随后在 10 月 4 日至 5 日期间标记并关闭了这些恶意节点，以阻断这一协同威胁。 攻陷 333 个节点（约占整个 Tor 网络的 10%）严重削弱了匿名路由系统旨在提供的隐私和安全性保障。此事件代表了开源生态系统中的一个重大漏洞，大规模的供应链和植入后门攻击可以绕过终端用户的安全防护，直接针对全球用户发起威胁。 此次攻击使用了名为 Ebury 1.8.3 的已知 OpenSSH 后门与凭据窃取工具（最初由 Windigo 团伙开发），该恶意程序最早就在 8 月份被部署。此行动的主要目标是收集未加密的邮件流量，并拦截 SSH 连接以窃取凭据并植入更多的后门程序。

rss · Solidot · 10月20日 15:22

**背景**: Tor（洋葱路由器）是一个匿名网络，它通过随机选择的三重中继器序列（入口、中间和出口）来路由用户流量。出口节点是连接 Tor 回路与开放互联网的最后一跳。Ebury 是一个高度复杂的恶意软件家族，主要针对 Linux 服务器和 OpenSSH 实现，它通常通过修改由合法 OpenSSH 可执行文件加载的共享库（.so 文件）来进行拦截并窃取凭据。
