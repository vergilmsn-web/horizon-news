## [Reladraw introduces text-based diagramming with manual node placement for AI agents](https://github.com/reladraw/reladraw) ⭐️ 7.0/10

Reladraw is a new diagram language that allows users to explicitly define node positions using relative coordinates while retaining text-based definitions similar to Mermaid. It is designed to be efficiently manipulated by both humans and AI agents, bridging the gap between automatic layout engines and manual editors. In the era of AI-assisted coding, visual alignment between developer mental models and agent understanding is a critical bottleneck for maintaining complex system architectures. Reladraw provides a streamlined, text-based interface that allows AI agents to quickly generate and iterate on diagrams with precise layout control without the overhead of traditional GUI editors. The tool features a relative positioning system that users have found practical enough to replace more complex absolute coordinate setups. An early community report noted that curved edge rendering can be inconsistent, and the project currently includes a skill installation method for integration with Claude or other agents.

hackernews · jpwalsh234 · Sep 26, 17:10 · [Discussion](https://news.ycombinator.com/item?id=49858513)

**Background**: Diagramming is essential for documenting software architecture and communication, with Mermaid and Graphviz popular for their text-based syntax. However, these tools rely entirely on algorithmic automatic layout, which often results in messy, unreadable structures for complex or non-standard diagrams. Conversely, manual tools like Draw.io offer full control but are highly inefficient for AI agents to manipulate programmatically, limiting their use in modern automated workflows.

## [Intel PresentMon 2.6.0 Cuts CPU Overhead and Adds Game Overlay](https://www.techpowerup.com/353118/intel-presentmon-2-6-0-update-slashes-cpu-usage-adds-game-experience-overlay) ⭐️ 5.5/10

Intel released PresentMon 2.6.0, which reduces the tool's own CPU overhead by up to 78% through optimized ETW flushing and background task timing. The update also introduces a new 'Game Experience' overlay preset that prioritizes perceived smoothness metrics over raw frame rate data. By significantly reducing self-inflicted performance drag, PresentMon 2.6.0 ensures that frame timing measurements are more accurate, as the monitoring tool itself is less likely to skew the results it is analyzing. The new overlay provides a more user-friendly view of performance for gamers who care about visual smoothness rather than just average FPS. The CPU reduction is achieved by using less aggressive timing for Event Tracing for Windows (ETW) flushing and adjusting diagnostic log processes. Additionally, the update supports per-metric multi-device selection, allowing telemetry from multiple GPUs to appear in the same overlay, while unavailable metrics are now dimmed with explanations instead of disappearing.

rss · TechPowerUp News · Sep 26, 15:29

**Background**: PresentMon is a free, open-source tool developed by Intel that captures detailed frame timing statistics, including CPU, GPU, and display latencies, across graphics APIs like DirectX, OpenGL, and Vulkan. It relies on Windows' Event Tracing for Windows (ETW) infrastructure to log kernel-level events with low overhead. High CPU usage in monitoring tools can create a feedback loop where the act of measuring performance actually degrades the performance being measured.
