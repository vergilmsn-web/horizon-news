## [GigaToken：语言模型分词速度提升约 1000 倍](https://github.com/marcelroed/gigatoken/) ⭐️ 7.0/10

GigaToken 是一个新的开源分词库，通过基于 SIMD 的优化、用自定义例程替代基于正则表达式的预分词，以及大幅优化预分词映射缓存，实现了相比现有实现约 1000 倍的速度提升。这些改进在现代 x86 和 ARM CPU 以及各种分词器配置下表现一致。 虽然分词在推理时间中通常只占不到 0.1%，但在对大规模训练语料进行离线数据准备时，它是一个主要瓶颈，因为需要将数 TB 的文本进行分词。1000 倍的速度提升可以显著缩短 ML 从业者准备训练数据集时的迭代周期并降低计算成本。 关键技术创新包括用 SIMD 优化的自定义代码替代基于正则表达式的预分词、最小化分支操作，以及积极缓存预分词映射。作者指出，结果在现代 x86 和 ARM CPU 以及各种特定的分词器实现上均保持一致。

hackernews · syrusakbary · 7月22日 17:20 · [社区讨论](https://news.ycombinator.com/item?id=49010167)

**背景**: 分词是自然语言处理中的预处理步骤，将原始文本转换为语言模型可以处理的 token（数字表示）。SIMD（单指令多数据）是一种 CPU 并行处理技术，允许单条指令同时对多个数据元素进行操作，显著加速字符串扫描等计算。预分词是在最终分词之前的初始分割步骤，将文本划分为多个块，通常使用正则表达式实现，在处理大规模数据集时可能成为性能瓶颈。

ServeTheHome 发布了一套方法论框架，用于将 NVIDIA Vera 最新白皮书中的基准测试结果进行标准化处理，以便与 AMD EPYC Turin 服务器处理器进行公平对比。该框架解决了测试配置和系统拓扑结构的差异问题，使两套 CPU 产品能够在同等条件下进行评估。 随着 NVIDIA 凭借 Vera 进入数据中心 CPU 市场，与 AMD 等成熟厂商展开竞争，公平的能效对比对于企业的采购决策至关重要。标准化框架有助于穿透厂商精心调优的基准测试营销手段，揭示不同服务器 CPU 在实际工作负载层面的真实差异。 该框架专门针对 NVIDIA Vera 与基于 Zen 5 架构的 AMD EPYC Turin 9005 系列之间的标准化，后者最高配备 192 核、TDP 为 500W，采用 SP5 插槽并支持 DDR5-6000（在 1DPC 配置下可达 6400 MT/s）。读者需要注意，Vera 的官方基准测试数据由 NVIDIA 自行挑选用于其白皮书，因此之所以需要这套标准化框架，正是因为原始数据本身无法直接比较。

**背景**: NVIDIA Vera 是该公司首款专为搭载 NVIDIA GPU 的加速系统设计的数据中心独立 CPU，主要面向智能体 AI、强化学习和数据处理工作负载。AMD EPYC Turin 是 AMD 服务器处理器的第五代产品，基于 Zen 5 架构打造，目前是高核心数数据中心部署中主流的 x86 替代方案。基准测试标准化通常需要调整核心数、内存带宽、TDP、编译选项以及工作负载配置等方面的差异，以便真正衡量架构效率而非原始的系统吞吐量。
