## [macOS Updates Full Disk Access for Granular Per-Folder Controls](https://developer.apple.com/news/?id=p6zjojqw) ⭐️ 6.0/10

Apple has updated the macOS Full Disk Access permission model to support more granular, per-folder access controls. This change allows applications to request specific directory access instead of requiring blanket permissions for the entire disk. This update significantly enhances user privacy by preventing apps from accessing the entire file system when only specific folders are needed. It is particularly relevant for AI agents and automation tools that can now operate within safer, scoped permissions. The new mechanism allows users to revoke specific folder grants later, and applications like Local Code can trigger the OS folder-grant interface when lacking access. There is currently user confusion regarding how to explicitly view and revoke individual folder permissions on a per-app basis.

hackernews · notfirstpost · Oct 2, 19:37 · [Discussion](https://news.ycombinator.com/item?id=49937631)

**Background**: macOS uses the Transparency, Consent, and Control (TCC) framework to manage app permissions, with Full Disk Access being one of the most critical privacy controls introduced in macOS Mojave. Traditionally, granting FDA gave an app unrestricted read access to the entire disk, whereas the new model allows for more restricted, folder-specific entitlements.

## [Microsoft Extends Advanced Shader Delivery to NVIDIA and Intel GPUs](https://www.techpowerup.com/353329/microsofts-advanced-shader-delivery-arrives-to-nvidia-geforce-rtx-gpus-later-this-month) ⭐️ 5.5/10

Microsoft has announced that Advanced Shader Delivery (ASD) support will arrive for NVIDIA GeForce RTX GPUs and Intel Arc B-Series later this month. This feature allows developers to ship pre-compiled shaders directly with games to optimize performance. Expanding ASD across major GPU ecosystems will help reduce in-game stuttering and loading times for PC gamers on diverse hardware. It addresses a common performance issue caused by the dynamic compilation of graphics code. Besides the new NVIDIA and Intel support, ASD currently works on AMD RDNA 1 through RDNA 4 and Qualcomm Snapdragon X2 Series. The Intel rollout specifically covers Arc B570, B580, Core Ultra Series 2, and Core Ultra Series 3.

rss · TechPowerUp News · Oct 2, 09:29

**Background**: Advanced Shader Delivery is a Microsoft technology that pre-compiles shaders to eliminate stuttering, a phenomenon where the game pauses while the GPU compiles graphics code in real-time. Prior to this update, the public preview of the feature was primarily supported on AMD RDNA GPUs.
