## [新分析表明 Blender 的 UI 运行时性能优于 GPUI](https://github.com/ppmpreetham/BUI) ⭐️ 6.0/10

一个新的名为 BUI 的 GitHub 项目提出了一项技术分析，证明 Blender 特定的 UI 和运行时架构比 GPUI 框架更快，这挑战了关于性能的普遍假设。 这一发现对寻找高性能 GUI 方案的 Rust 生态开发者意义重大，因为它凸显了在特定复杂场景下，类似即时模式的自定义运行时有时能胜过现代的声明式框架。 该项目指出，虽然 GPUI 针对简单界面进行了高度优化，但与其专用架构相比，它在复杂、数据密集型 UI 场景中缺乏性能优势。社区反馈还表示，Iced 和 Slint 等其他 Rust GUI 库实际上可能比 GPUI 更快。

hackernews · ppmpreetham · 11月6日 07:40 · [社区讨论](https://news.ycombinator.com/item?id=50389333)

**背景**: GPUI 是一个用 Rust 编写的状态驱动、声明式用户界面框架，被 Zed 代码编辑器广泛使用。相比之下，Blender 使用了一个高度定制的、类似即时模式的 UI 系统，允许与其渲染引擎和复杂数据结构进行深度集成，使其成为 GUI 性能的一个独特案例研究。

**社区讨论**: 虽然一些开发者称赞 Blender UI 的优雅和可定制性，但其他人强烈反对在 3D 建模之外使用如此复杂的系统。一场重要的技术辩论集中在 GPUI 的实际速度上，有用户认为与 Iced 或 Slint 等替代方案相比，它并非最快的选择。
