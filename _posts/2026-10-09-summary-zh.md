## [Cloudflare 收购 Deno，独立运行时开发将终止](https://deno.com/blog/cloudflare) ⭐️ 9.0/10

Cloudflare 已收购 Deno，Deno 团队全员加入该公司。Deno 运行时将在一年内每月提供漏洞修复和安全更新，之后官方开发将正式停止。 此次收购标志着 JavaScript 运行时领域的整合，使得 Bun 成为 Node.js 少数主要的独立替代方案之一。这对依赖 Deno 安全优先模式和简洁性的开发者产生了影响，生态系统正转向 Cloudflare 的基础设施。 尽管 Deno 仍保持开源状态，但 Cloudflare 将在一年停止自身开发，且 Deno Deploy 将在六个月内关闭。JavaScript 包平台 JSR 将继续运营，但其基础设施将迁移至 Cloudflare 服务器。

hackernews · ilreb · 10月9日 13:03 · [社区讨论](https://news.ycombinator.com/item?id=50019911)

**背景**: Deno 是由 Node.js 创始人 Ryan Dahl 创建的 JavaScript 和 TypeScript 运行时，以其安全优先的方法著称，默认限制对文件系统和网络的访问。与使用 npm 的 Node.js 不同，Deno 拥有独特的包生态系统和内置工具。

## [微软发布 MXC：跨平台沙盒代码执行系统](https://github.com/microsoft/mxc) ⭐️ 7.0/10

微软发布了 MXC，一个用于管理 Linux、Windows 和 macOS 进程隔离和权限的统一 API 开源沙盒代码执行系统。它抽象了 bubblewrap、seatbelt 和 processcontainer 等复杂的操作系统特定机制，以限制模型生成的输出和插件等不可信代码。 对于开发安全敏感应用或 AI 代理环境的开发者而言，该工具具有重要意義，因为它提供了一種在策略驅動限制下執行不可信代碼的一致方法，而無需使用完整的虛擬機。通過抽象操作系統特定的差異，它降低了涉及模型生成代碼或動態工作負載的代理場景中沙盒化的複雜性。 MXC 包含用於確定所需權限的“學習”模式並使用 MIT 許可證，但與 Windows 和 Linux 相比，它目前在 macOS 上缺乏細粒度網絡控制（如通過主機名或 CIDR 允許/拒絕）。該實現基於大約 35 萬行 Rust 代碼，並且沒有導入其上游沙盒依賴關係。

hackernews · nreece · 10月9日 05:51 · [社区讨论](https://news.ycombinator.com/item?id=50016489)

**背景**: 沙盒化是一項安全技術，通過限制進程的能力來防止其損害宿主系統，這對於執行 AI 生成的腳本等不可信代碼至關重要。不同的操作系統使用不同的隔離機制——Linux 通常使用命名空間或 bubblewrap，macOS 使用 seatbelt，Windows 使用進程容器——這使得跨平台一致性成為開發者的主要挑戰。
