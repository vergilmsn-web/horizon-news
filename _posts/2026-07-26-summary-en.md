## [Anthropic Releases New Context Engineering Guidance for Claude Models](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models) ⭐️ 6.0/10

Anthropic published an official blog post outlining new context engineering practices for its latest Claude generation, shifting emphasis from isolated prompt crafting to programmatically assembling prompts, retrieved documents, memory, and tools for each inference. The guidance places notable weight on the platform's auto-memory feature as a core mechanism for managing long-running agent workflows. Context engineering has rapidly become the dominant framing for production LLM work, so official guidance from a frontier lab directly shapes how teams build agents, manage cost, and think about liability. The choice to elevate auto-memory and external tooling also signals a strategic move toward deeper platform lock-in at the expense of portable, file-based workflows. The post distinguishes context engineering from traditional prompt engineering by framing the context window as a curated assembly of prompts, retrieved documents, memory stores, and tool outputs rather than a single hand-written instruction. It leans heavily on Claude's auto-memory, a feature that writes notes about debugging patterns, architecture decisions, and user preferences across sessions, but whose recall behavior several practitioners describe as opaque and prone to unsupported assumptions.

hackernews · mellosouls · Jul 25, 20:42 · [Discussion](https://news.ycombinator.com/item?id=49051361)

**Background**: Prompt engineering traditionally referred to crafting individual text inputs to steer an LLM's output, which works well for narrow, predictable tasks. Context engineering broadens this to the programmatic assembly of everything the model sees at inference time, including retrieved documents from RAG systems, memory from prior sessions, and structured tool outputs. Claude's auto-memory feature automatically records observations such as debugging patterns, build commands, and architecture decisions so they can be reused in later sessions, sitting alongside user-maintained files like CLAUDE.md and MEMORY.md that traditionally held such configuration in plain Markdown.

## [Vatican's 'Click to Pray' app exposed 700K+ users via unauthenticated API](https://www.tomshardware.com/tech-industry/cyber-security/security-flaw-in-vaticans-click-to-pray-app-leaves-over-700-000-global-users-exposed-app-has-been-leaking-user-data-for-over-six-months-and-still-does) ⭐️ 5.5/10

Security researchers discovered that the Vatican's official 'Click to Pray' app exposed the personal data of over 700,000 global users — including names, email addresses, and birthdates — because its backend API had zero authentication. The flaw remained exploitable for at least six months before being fixed, and the developers reportedly took no action during that period. The incident is significant because it affected a very large user base associated with a globally recognized institution, and the vulnerability — missing API authentication — is among the most fundamental and easily preventable security oversights. It highlights how even high-profile organizations can fail at basic security hygiene, putting sensitive personal and potentially religious-affiliation data at risk. The exposed data included personally identifiable information such as names, email addresses, and birthdates, all accessible through a backend API that required no authentication token or credentials of any kind. The flaw went unaddressed for over six months despite the app's large user base, and the underlying issue is a textbook case of an unprotected API endpoint — a vulnerability class that tools like those described by Palo Alto Networks and PortSwigger classify as critical-severity.

rss · Tom's Hardware · Jul 25, 17:56

**Background**: An API (Application Programming Interface) serves as the backend communication channel between a mobile app and its server, handling data exchange such as user profiles. API authentication is the process of verifying that a request to the API comes from a legitimate, authorized user — typically via API keys, OAuth tokens, or JWT (JSON Web Tokens). When an API has 'zero authentication,' it means anyone on the internet can directly query the server and retrieve data without presenting any credentials, making the entire user database trivially accessible to attackers or even casual observers.

## [Game Compressor: $6 Utility Saves Hundreds of GB Using Windows LZX](https://www.tomshardware.com/pc-components/storage/game-compressor-can-save-you-hundreds-of-gigs-across-your-game-library-usd6-utility-leverages-windows-built-in-lzx-compression-for-substantial-space-savings) ⭐️ 5.5/10

A $6 utility called Game Compressor, developed by Stone Pit Sons, uses Windows' built-in LZX compression to reduce the storage footprint of PC game libraries by up to 50%, potentially saving users hundreds of gigabytes across their installed games. With SSD and high-capacity storage prices remaining elevated, a lightweight, low-cost tool that can reclaim significant disk space without sacrificing game performance offers practical relief for gamers with large libraries, especially those on smaller or full drives. The tool claims zero FPS loss and instant playability by leveraging Windows' native LZX architecture rather than custom compression, and includes a smart estimation system that previews approximate space savings before committing to compression of any given game.

rss · Tom's Hardware · Jul 25, 11:00

**Background**: LZX is a compression algorithm from the LZ77 family, created by Jonathan Forbes and Tomi Poutanen in the 1990s as an improved variant of DEFLATE. Microsoft integrated LZX into Windows for use with the NTFS file system, and starting with Windows 10, users can apply LZX compression to individual files and folders — it is the strongest compression algorithm available for NTFS. Traditional NTFS compression uses a lighter algorithm, so LZX offers better compression ratios at the cost of slightly more CPU overhead. Tools like Game Compressor essentially serve as user-friendly front-ends that automate applying this OS-level capability to large game directories.
