This was achieved by creating a custom Direct3D 9 bridge that connects the legacy game's rendering code to modern NVIDIA RTX-capable hardware. Legacy games like Grand Theft Auto 2 from 1997 typically rely on older graphics APIs such as DirectX 8 or 9, which lack support for modern hardware features like ray tracing.
