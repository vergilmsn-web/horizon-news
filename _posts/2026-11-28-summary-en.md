## [Unkernel Compiles Real Linux Kernel to WebAssembly for Browser Execution](https://unkernel.dev/) ⭐️ 8.0/10

Unkernel is a project that successfully compiles the genuine Linux kernel to WebAssembly, enabling it to boot to a shell in under one second within a web browser. This approach allows concurrent user processes to run directly in the browser environment using a custom aarch64 CPU emulator called kwemu. This project demonstrates a significant breakthrough in web isolation and emulation by allowing non-web-native software to run securely inside a browser. It opens new possibilities for running system-level tools and demonstrating the capabilities of WebAssembly for complex computing tasks within a constrained sandbox. The implementation relies on kwemu, an aarch64 CPU written in Zig that is linked into the kernel, which walks the kernel's own page tables to handle memory management via real Linux code. The system supports concurrency, as demonstrated by multiple parallel processes, but nested virtualization is not supported.

hackernews · nreece · Nov 28, 03:19 · [Discussion](https://news.ycombinator.com/item?id=50674218)

**Background**: WebAssembly (Wasm) is a binary instruction format designed to provide a portable, low-level code model that runs on multiple platforms, including web browsers. Compiling a full operating system kernel like Linux to Wasm is an advanced systems research effort that requires emulating CPU architecture and managing memory manually, as the kernel cannot use standard OS services in this context. Unkernel differs from traditional QEMU-style emulators by emulating only the user programs while running the actual Linux kernel code.

## [Google DeepCrossAttention Improves Transformer Efficiency](https://research.google/blog/supercharging-transformer-residual-connections/) ⭐️ 8.0/10

Google Research has introduced DeepCrossAttention, a method that applies attention mechanisms across layers rather than just tokens to enhance residual learning in transformers. This innovation achieves up to 3x faster inference while maintaining comparable model quality. This optimization is significant for the AI industry as it reduces computational costs and improves speed for large language models. By addressing the high cost of scaling traditional attention, it helps make advanced AI capabilities more accessible and efficient. The mechanism uses learnable, input-dependent weights to dynamically combine prior layer embeddings, unlocking the model's full historical context without the typical computational penalty. This depth-wise cross-attention specifically operates on the residual connections between layers.

hackernews · ComputedCamp995 · Nov 27, 23:06 · [Discussion](https://news.ycombinator.com/item?id=50672565)

**Background**: Standard transformer models use attention mechanisms to process tokens within a sequence, but residual connections simply add the output of each layer to the original input. As models deepen, managing this information flow becomes complex and computationally expensive. DenseNet is a known architecture that connects layers to all subsequent layers, a concept similar to the cross-layer focus of this new research.

Intel Foundry released a white paper detailing how advanced power delivery innovations, such as backside power delivery and silicon capacitors, are needed to meet the extreme power demands of AI data center accelerators. The document emphasizes that power delivery is now a critical bottleneck limiting performance in next-generation hardware. As AI chips operate at lower voltages and higher power consumptions, traditional power delivery networks face severe voltage droop and resistive losses. Addressing these physical limitations is essential for improving the performance-to-watt ratio of data center infrastructure and sustaining the growth of AI workloads. The white paper identifies a scenario where a 5 kW AI GPU can lose a significant portion of its power before it reaches the compute dies, and proposes integrated voltage regulators and silicon capacitors to improve efficiency. It also examines the shifting power requirements across the hierarchy of the accelerator, rack, and data center.

rss · SemiWiki · Nov 27, 14:00

**Background**: Power delivery networks (PDNs) are the complex routing structures that distribute electrical power to the billions of transistors on a chip. As semiconductor technology advances, chips require more power at lower voltages, which increases the current and the energy lost as heat in the distribution system. Backside power delivery is a technique where power distribution layers are moved to the opposite side of the silicon to reduce the distance and resistance between the power source and the transistors.
