## [OmniDiff: Open-source, fast, content-aware Git diff tool in Rust](https://github.com/ivankovic/omnidiff) ⭐️ 6.0/10

OmniDiff is an open-source Rust-based Git difftool that provides fast, content-aware diffs for over 25 programming languages, images, and PDFs. The tool is currently at version 0.3.0 and claims to process large C++ files in under 100ms. The tool offers a performance-oriented alternative to existing diff viewers like Delta, specifically targeting complex merge conflicts and multi-file-type support in a lightweight executable. It empowers developers with faster feedback loops during development and code reviews. OmniDiff is licensed under AGPLv3 and its development was informed by sampling and manually resolving 2,000 real-world diffs from 7,400 Gentoo repositories. It supports configuration as a `git difftool` and includes a web version and CI pipeline for robustness.

hackernews · FabCH · Nov 1, 13:02 · [Discussion](https://news.ycombinator.com/item?id=50325253)

**Background**: A Git difftool is an external command used to visualize changes in Git repositories, replacing the default terminal output. Standard tools often treat all text the same, whereas content-aware tools use specific logic to parse code structures. Delta is a popular Python-based alternative that provides syntax highlighting and side-by-side views.

**Discussion**: The discussion is positive and technically focused, with the original creator of `git difftool` reaching out to offer upstreaming support. Users highlight practical integration needs, such as piping via `git diff | omnidiff` and the lack of a feature similar to Delta's 'diff-so-fancy' character highlighting.
