## [台积电 2 纳米制程流片量增长四倍](https://www.techpowerup.com/350827/tsmcs-2-nm-node-gains-momentum-with-fourfold-increase-in-tape-outs) ⭐️ 7.5/10

台积电高级副总裁张晓强确认，N2（2 纳米）制程的芯片流片数量已达到上一代 N3（3 纳米）制程的四倍，知名客户包括 AMD 的 EPYC"Venice"服务器 CPU 以及苹果用于 iPhone 18 Pro 系列的 A20 Pro 芯片。 流片数量四倍的增长表明业界对台积电 2 纳米 GAAFET 技术充满信心，也意味着许多客户正加速跳过 3 纳米节点。随着这些设计进入大规模量产，台积电的晶圆营收和季度业绩有望大幅增长，进一步巩固其在先进制程制造领域的领先地位。 凭借台积电首次采用的 GAAFET 纳米片晶体管，N2 在相同功耗下可实现高达 15%的性能提升，或在相同速度下降低高达 30%的功耗，晶体管密度较 N3E 提升约 15%。尽管 N2 已于 2025 年第四季度开始大规模量产，但目前仅占台积电营收的 3%，而 N3 占 30%、N5 占 33%。

rss · TechPowerUp News · 7月16日 16:12

**背景**: 流片是芯片设计中的关键里程碑，指将最终版图交付给代工厂进行掩膜制作和晶圆制造，代表着工程资源的大量投入。台积电 N2 节点首次采用 GAAFET（环栅 FET）架构，栅极从四个方向完全包裹沟道，相比早期节点使用的 FinFET 晶体管，具有更优的静电控制、更低的漏电流和更好的可扩展性。这种架构变革被广泛视为 5 纳米以下制程中 FinFET 的天然继任者，因为平面和鳍式设计在该尺度下会遇到根本性的物理极限。工艺设计套件（PDK）则提供晶体管模型、设计规则和仿真库，使无晶圆厂的设计人员能够创建与特定代工节点兼容的电路版图。

## [Shark 扫地机器人 AWS IoT 策略漏洞可实现横向 Root 访问](https://www.tomshardware.com/tech-industry/cyber-security/shark-robot-vacuum-flaw-lets-one-stolen-certificate-run-root-commands-on-others-in-the-same-aws-region) ⭐️ 7.5/10

Shark 扫地机器人存在一个尚未修复的漏洞，根源在于其过度宽松的 AWS IoT 策略，导致单个被盗的 X.509 证书能够在同一 AWS 区域内其他 Shark 扫地机器人上执行 Root 级命令。 该漏洞允许攻击者在消费级 IoT 设备之间进行横向移动，从而暴露实时摄像头画面、家庭地图和 Wi-Fi 凭证——这意味着一台设备被攻破就可能让攻击者获得受害者家庭和网络的详细信息。 根本原因是附加在设备证书上的 AWS IoT 策略权限过于宽泛（可能横跨整个 Thing Group 或区域范围），而未遵循每个设备单独限定权限的最小特权原则。

rss · Tom's Hardware · 7月17日 10:00

**背景**: AWS IoT Core 是一项托管云服务，允许联网设备使用 MQTT 协议与 AWS 进行通信。每个物理设备被称为一个"Thing"（物品），在 AWS 中注册时拥有自己的 X.509 证书和附加的 IoT 策略，用于定义该设备被授权执行的操作。当 IoT 策略编写得过于宽松时（例如使用通配符或将同一策略应用于整个 Thing Group），单个设备上被盗的证书就可能让攻击者获得远超该设备范围的访问权限。在此事件中，过度宽松的策略使得单个被盗证书能够冒充或控制同一 AWS 区域内的其他扫地机器人。
