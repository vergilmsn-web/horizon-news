## [Girl Dies After First Brain-Targeted Base Editing Gene Therapy Trial](https://www.solidot.org/story?sid=84912) ⭐️ 9.3/10

In March 2025, a 6-year-old girl named Meimei died seven days after receiving the world's first brain-targeted base editing gene therapy at Shanghai Xinhua Hospital. The experimental treatment, developed by Shanghai Jiao Tong University professor Qiu Zilong using AAV9-delivered base editing to correct a CHD3 mutation causing Snijders Blok-Campeau syndrome, triggered a severe immune reaction that led to her death. This is the first reported death from a brain-targeted gene editing human trial and involves the very scientist (Qiu Zilong) who previously condemned He Jiankui's unethical embryo editing, raising serious questions about scientific misconduct, informed consent failures, and the ethics of experimenting on a mildly symptomatic patient. The case exposes weak regulatory oversight—the hospital was fined only ~24,000 RMB while no individuals were penalized—and could significantly damage public trust in gene therapy research in China and globally. The therapy used base editing (which chemically converts one DNA letter to another without cutting the double helix) rather than conventional CRISPR-Cas9, delivered via AAV9 viral vector injected into cerebrospinal fluid. Notably, Meimei's symptoms were classified as mild—experts questioned whether surgery was medically necessary—and the parents allege the informed consent form downplayed mortality risk, failing to explicitly mention death as required for first-in-human trials. The family's request to retract the Nature paper (which allegedly omitted the trial failure) has not been publicly addressed.

rss · Solidot · Jul 24, 07:47

**Background**: Base editing is a newer gene editing technology that chemically converts one DNA base to another without creating double-strand breaks, offering greater precision than conventional CRISPR-Cas9 for correcting point mutations like the CHD3 C-to-T change in this case. AAV9 (adeno-associated virus serotype 9) is a viral vector particularly effective at crossing the blood-brain barrier, making it useful for delivering gene therapies to the central nervous system. Snijders Blok-Campeau syndrome is an extremely rare autosomal disorder (only 237 confirmed cases worldwide) caused by CHD3 mutations that impair chromatin remodeling, leading to intellectual disability and other neurological symptoms with highly variable severity. Qiu Zilong's involvement is especially controversial given his public role in condemning He Jiankui's 2018 CRISPR-edited babies scandal in China.

## [Postgres LISTEN/NOTIFY Demonstrates Real Scalability](https://www.dbos.dev/blog/postgres-listen-notify-scalability) ⭐️ 7.0/10

DBOS published a technical analysis showing that Postgres's LISTEN/NOTIFY mechanism can scale to tens of thousands of notifications per second, directly challenging a widely-shared 2025 blog post claiming that it does not scale. LISTEN/NOTIFY provides a built-in pub/sub primitive that lets developers avoid introducing separate message brokers like Redis or Kafka for many use cases, simplifying architecture and preserving transactional consistency with the database. Demonstrating real-world scalability reshapes architectural decision-making for backend teams building event-driven systems on Postgres. The analysis targets scenarios reaching roughly 60K notifications per second, and the original counter-post it responds to issued an errata acknowledging earlier locking-related performance issues that have since been resolved in modern Postgres versions. The discussion notes that scalability is contextual rather than binary — what suffices for one workload may fall short for another.

hackernews · KraftyOne · Jul 24, 19:05 · [Discussion](https://news.ycombinator.com/item?id=49040296)

**Background**: PostgreSQL's LISTEN and NOTIFY commands enable asynchronous communication between database sessions: a client LISTENs on a named channel, and another session issues NOTIFY to push a lightweight payload (up to 8000 bytes) to all subscribed listeners. This provides a simple, database-integrated alternative to dedicated pub/sub systems such as Redis Pub/Sub or Kafka. Historically, the mechanism has carried a reputation for poor scalability due to early locking bottlenecks, leading many developers to dismiss it for high-throughput applications without testing.

The exposure was traced to a Vite build error that leaked sensitive internal infrastructure details into the production firmware. This incident highlights systemic IoT security failures in commercial surveillance products, where hardcoded credentials and exposed internal infrastructure can give attackers potential access to both customer networks and the vendor's own development systems. It raises serious concerns about the security practices of major camera manufacturers and the supply-chain risks inherent in widely deployed IoT devices. The root cause was a Vite build configuration error that inadvertently included environment variables (including a GitHub admin token and internal IP addresses) in the compiled JavaScript bundle served by the camera's web interface. GitHub admin tokens, if valid and not revoked, could grant broad access to the organization's repositories, CI/CD pipelines, and internal code—potentially enabling supply-chain attacks against all customers using affected firmware.

In IoT devices like security cameras, such credentials are particularly dangerous because firmware is often publicly accessible or extractable, and devices may remain in service for years without updates. Vite is a popular modern JavaScript build tool; misconfigurations in how it handles environment variables during the build process can cause sensitive data to leak into client-side code bundles.
